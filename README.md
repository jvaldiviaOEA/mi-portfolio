# mi-portfolio

Portfolio personal de Juan Pérez — Backend developer.

Características:
- React + Vite (ligero y rápido).
- Mobile-first y accesible (focus-visible, contraste).
- Tipografía: Montserrat (Google Fonts).
- Paleta: colores llamativos pero con tono serio (púrpura + cian).

Educación / Cursos:
- Creating a microservice
- Java 21
- Scrum master

Instalación local:
1. Asegúrate de tener Node 18+.
2. Instala dependencias:
   npm install
3. Ejecuta en desarrollo:
   npm run dev
4. Construir para producción:
   npm run build

Siguientes pasos:
1. Revisas el diseño/texto.
2. Si das OK, creo el repositorio público `mi-portfolio` y subo estos archivos.
3. Configuramos despliegue en Vercel (conectar repo y desplegar).
